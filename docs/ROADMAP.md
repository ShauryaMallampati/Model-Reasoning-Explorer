# Roadmap

## Near Term
- Richer layer selection UI and presets
- Attention pattern exploration improvements
- Enhanced counterfactual search for text and images
- Better dataset slicing and report templates

## Mid Term
- Share-link backend storage and permissions
- Multi-modal inputs (text + image)
- Cross-run neuron and feature tracking
- Expand plugin system for custom analyzers

## Long Term
- Collaborative sessions and shared annotations
- Remote compute workers
- Advanced causal tracing and patching tooling
- Model-specific adapters for non-Transformer architectures
